# linux-tokyo-ghoul-rice-dotfiles

Personal Linux ricing setup: Tokyo Ghoul themed, distro-independent where possible.

## Machines

- **Laptop** — Fedora KDE Plasma (Wayland) — *Rize* theme
- **Workstation** — Fedora KDE Plasma (X11, VMware VM) — *Touka* theme

## Structure

- `shell/` — bash, aliases, prompt config
- `terminal/kitty/` — kitty terminal config + per-theme variants
- `kde/` — Plasma global themes, color schemes, Kvantum themes (per character)
- `wallpapers/` — wallpaper sets, organized by theme
- `system/` — SDDM, Plymouth, GRUB themes (distro-coupled)
- `install/` — bootstrap scripts per distro
- `docs/` — notes, screenshots, reference

## Status

🚧 Migration from Mint in progress. Touka theme not started yet.
